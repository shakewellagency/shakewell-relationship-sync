# Shakewell Two-way Relationships for ACF

> **Made by [Shakewell](https://shakewell.agency).** Free and open source, built and maintained by the Shakewell team.

See `readme.txt` for what it does and how to use it.

```sh
composer install
npm ci
npm run env:start
npm test
composer lint
npm run plugin-check
npm run env:stop
```
